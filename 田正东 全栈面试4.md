二、项目介绍（Project Introduction，约1-2分钟）
 
  
Hello, let me talk about my main project.
I built a full-stack SaaS platform for foreign trade shoe sellers.
I used Bun + TypeScript + Next.js for the whole project, and PostgreSQL with Redis for data.
 
First, I used Bun to make builds much faster. It helped us cut build time by 60%.
Then, with Next.js, I made pages load 40% faster, using both SSR and CSR.
 
For safety, I used Drizzle ORM and Zod.
This made the types the same from database to front-end,
 
Also, I used Claude Code to write code and check rules.
It helped keep all modules clean and consistent.
 
The final system let sellers manage products and build their own online stores. 
It solved their problems with many products and slow websites.
 
I learned a lot about high-performance apps and multi-tenant systems from this project.
