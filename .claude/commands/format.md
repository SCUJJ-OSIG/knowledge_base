# 用途

只整理 vault 内 .md 文件的**纯格式问题**,不改任何语义、不加任何文字、不删任何内容。

# 处理范围(只动这些)

| 类别 | 修正 |
|------|------|
| 标题层级 | `#`/`##`/`###` 顺序合理,跳级的补齐或降级 |
| 列表风格 | 统一用 `-` 开头,避免 `*` / `1.` 与 `-` 混用 |
| 代码块 | 给裸 ``` 补语言标签(根据上下文猜:`bash` / `ts` / `json` / `powershell` / `toml` 等) |
| 表格 | 对齐 `|` 列宽,补齐缺失的 `\|---\|` |
| 空行 | 多余空行压成单个,段间保留 1 个空行 |
| 中英文 | 中文与英文/数字之间补一个空格(中英文标点间不补) |
| 引用块 | 同一段引用用 `> ` 开头(空行不中断) |
| frontmatter | 字段顺序统一(`date created` → `date modified` → `tags` → `形态` → `场景` → `published` → `series`) |
| 缩进 | 列表嵌套用 2 空格,不用 Tab |
| 行尾空格 | 删除行尾空白 |

# 严禁(做了就是越界)

- ❌ **不加任何文字**:不补注释、不加"如下所示"、不写小标题说明
- ❌ **不改写原文**:不替换词语、不调整语序、不润色句子
- ❌ **不删内容**:不删任何正文、图片引用、链接
- ❌ **不动 wikilink**:`[[xxx]]` 和 `![[xxx]]` 原样保留,只改文件内部格式
- ❌ **不动 frontmatter 值**:只重排字段顺序,不改字段内容
- ❌ **不动代码块逻辑**:只补标签/缩进,不修代码

# 工作流

1. **读** → 读取目标 .md(默认参数 = 当前打开的文件)
2. **扫描** → 用 Grep/Read 找格式违例点,**不要**整体重写
3. **小步 Edit** → 每个违例点单独 Edit,旧字符串必须唯一
4. **review** → 改完后 Read 回来检查,确认没动到正文
5. **不自动 commit** → 改完等用户确认

# 参数

| 参数 | 行为 |
|------|------|
| `/format` | 整理当前打开的 .md |
| `/format <文件名>` | 整理指定文件(走 vault 根查找) |
| `/format --scan` | **只扫描不改**,输出乱度排行榜(走 `bun scripts/format-scan.ts`) |
| `/format --scan --threshold 3` | 扫描时只显示乱度 ≥ 3 的(可叠加) |
| `/format --scan --top 30` | 扫描时显示前 30 名(可叠加) |
| `/format --all` | 整理 vault 根所有 .md(慎用,先 scan 后改) |

## /format --scan 详细

1. **不修改任何文件**,只读 vault 所有 .md
2. 按 10 类违例各 +1 计算"乱度"
3. 输出 TOP 排行 + 每篇的具体问题位置

**何时用**:
- 不确定哪些文件最乱 → 先 `--scan`
- 想偷懒一次看完 → `--scan --top 20`
- 想看最干净的临界 → `--scan --threshold 1`

**输出示例**(摘要):
```
## 格式扫描报告
扫了: 161 个 .md
乱度 ≥ 5: 23 个
干净(< 5): 138 个

### TOP 15 乱度排行
#### 12. `2-技术文章/.../Docker部署流程实践笔记.md` (608 行)
  - [标题跳级: `#` → `###`]
  - [裸代码块(共 3 个)] [×3]
  ...
```

# 报告格式(改完输出)

```
## format 报告
文件: <path>
改动: <N> 处
- [标题] 第 X 行: <具体改动>
- [代码块] 第 X-Y 行: 补语言标签 `bash`
- [空行] 第 X 行: 合并 3 行空行 → 1 行
- ...
未改动: 列出扫描过但无需改的项
```
