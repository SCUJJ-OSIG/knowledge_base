目标：自动忽略 `node_modules`、Python 虚拟环境、Android 构建目录、Rust 编译缓存等项目依赖文件夹，避免索引大量无用文件、加快索引速度、减少搜索干扰。

> 界面对应：选项 → 索引 → **排除列表**（你截图页面）

## 一、先看懂当前面板选项说明

1. **排除隐藏文件和文件夹 (H)** 按需勾选；开发环境很多缓存目录是隐藏目录，不建议无脑勾选，避免误杀需要查找的隐藏配置文件。
    
2. ✅ **排除系统文件和文件夹 (S)** 保持勾选，屏蔽 Windows 系统目录，默认推荐开启。
    
3. ✅ **启用排除列表 (E)** 必须勾选，下方规则才生效。
    

> 三个输入区域作用区分：

- **排除文件夹 (O)**：**重点使用**，按文件夹路径 / 名称匹配，最适合屏蔽各类依赖目录
    
- **仅包含文件 (I)**：白名单，只索引指定文件，一般开发场景不用
    
- **排除文件 (X)**：按文件名匹配，适合屏蔽特定后缀文件，本次需求以文件夹排除为主
    

## 二、配置方案（两种方案任选，推荐方案 2【名称匹配】）

> ⚠️ 重要知识点： Everything 排除列表支持**文件夹名称全局匹配**，直接填写文件夹名，所有磁盘下同名文件夹全部自动排除，不需要写完整路径。

### 方案 1：全局名称匹配（推荐！一次配置，所有项目生效）

点击【添加筛选器 (L)...】，依次添加下面这些目录名称

```Plain
node_modules
venv
.venv
__pycache__
build
dist
target
.gradle
build-cache
.idea
.vscode
cmake-build-debug
cmake-build-release
Pods
carthage
```

完整清单释义：

|   |   |
|---|---|
|文件夹名称|作用|
|node_modules|JS/TS 前端依赖库|
|venv / .venv|Python 虚拟环境|
|**pycache**|Python 字节码缓存|
|target|Rust Cargo 编译产物|
|build / dist|通用编译输出目录|
|.gradle|Android Gradle 缓存|
|.idea|JetBrains IDE 缓存（可选排除）|
|.vscode|VSCode 工作区缓存（可选）|

操作步骤：

1. 点击【添加筛选器 (L)...】
    
2. 填入文件夹名称，类型选择【文件夹】
    
3. 重复操作把上面所有目录添加完成
    

### 方案 2：路径匹配（如果你只想排除特定磁盘下的目录，不推荐全局）

点击【添加文件夹 (F)...】，选择具体路径，适合只屏蔽单一项目，**换项目就失效**，开发多项目不建议。

## 三、【关键避坑】操作完成后的必要步骤

1. 点击【应用】→【确定】关闭窗口
    
2. 菜单栏：**索引 → 强制重建**
    

> 旧的索引依然包含这些目录，必须重建索引，新排除规则才会生效！

## 四、进阶优化补充规则（可选添加）

### 排除文件（填入「排除文件 (X)」输入框）

屏蔽编译生成的中间文件，多个用 `;` 分隔

```Plain
*.pyc;*.class;*.o;*.obj;*.log
```

### 不建议无脑排除的目录提醒

`.git`：不要排除！经常需要搜索 git 仓库内代码文件，保留索引。

## 五、备份配置（迁移 / 重装 Everything 用）

Everything 配置文件路径： `%APPDATA%\Everything\Everything.ini` 搜索 ini 内 `exclude_folders`、`exclude_files` 字段，所有排除规则保存在这里，重装 Beta/Alpha 预览版直接复制覆盖即可。
