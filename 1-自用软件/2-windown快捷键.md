### 一、Windows 常用命令（CMD/PowerShell）

| 命令          | 功能说明                    |
| ----------- | ----------------------- |
| ipconfig    | 查看网络配置信息（IP地址、子网掩码、网关等） |
| tracert     | 追踪数据包从本地到目标主机的路径，排查网络故障 |
| route       | 管理本地路由表（查看、添加、删除路由规则）   |
| route print | 打印本地路由表详细信息             |
