## Git 常用命令

### 核心概念

参考 [[Git版本控制]] 了解 Git 的基本原理。

### 日常高频命令

#### 基础操作

```bash
# 克隆仓库
git clone <url>

# 查看状态
git status

# 查看变更
git diff

# 查看提交历史
git log --oneline
```

#### 暂存与提交

```bash
# 添加文件到暂存区
git add <file>
git add .                    # 添加所有变更

# 提交
git commit -m "描述"
git commit --amend           # 修改上次提交
```

#### 分支管理

```bash
# 创建并切换分支
git checkout -b <branch-name>
git switch -c <branch-name>  # Git 2.23+

# 查看分支
git branch
git branch -a                # 查看所有分支

# 切换分支
git checkout <branch-name>
git switch <branch-name>

# 删除分支
git branch -d <branch-name>  # 安全删除
git branch -D <branch-name>  # 强制删除
```

#### 远程操作

```bash
# 查看远程仓库
git remote -v

# 添加远程仓库
git remote add origin <url>

# 拉取远程代码
git pull origin <branch>
git pull --rebase            # 变基方式拉取

# 推送代码
git push origin <branch>
git push -u origin <branch>  # 设置上游分支

# 推送标签
git push --tags
```

#### 合并与变基

```bash
# 合并分支
git merge <branch>

# 变基操作
git rebase <branch>
git rebase --abort           # 中止变基
git rebase --continue        # 继续变基
```

#### 撤销操作

```bash
# 撤销工作区修改
git checkout -- <file>
git restore <file>           # Git 2.23+

# 撤销暂存
git reset HEAD <file>
git restore --staged <file>

# 撤销提交
git reset --soft HEAD~1      # 保留暂存
git reset --hard HEAD~1      # 全部丢弃
```

#### 标签操作

```bash
# 创建标签
git tag v1.0.0
git tag -a v1.0.0 -m "版本说明"

# 查看标签
git tag
git show v1.0.0
```

### 常见问题

#### 合并冲突

```bash
# 1. 找到冲突文件
git status

# 2. 手动编辑解决冲突

# 3. 标记解决
git add <resolved-file>

# 4. 完成合并
git commit
```

#### 错误推送恢复

```bash
# 如果推送了敏感信息，立即删除
git reset --hard HEAD~1
git push --force
```
