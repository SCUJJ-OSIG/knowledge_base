学习方向
在学习了解react和vue 之后，我决定以后专心react 。 vue 更加出众在vite 而不是vue。

| 对比维度      | Vue         | React              |
| :-------- | :---------- | :----------------- |
| 生态丰富度     | 生态相对较弱      | 生态更完善、资源更多         |
| 语法与灵活度    | 语法固定、写法约束较多 | 语法更灵活，可操作性更强       |
| 上手直观度     | 看起来更简单、易入门  | 上手门槛相对高一点          |
| 主流 SSR 框架 | Nuxt        | Next.js            |
| 框架启动速度    | 启动速度较慢      | 启动速度明显更快           |
| 服务端渲染能力   | 服务端数据获取相对繁琐 | 服务端可直接写数据库查询，开发更便捷 |
