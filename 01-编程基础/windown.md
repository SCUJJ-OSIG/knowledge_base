## Windows 系统常用快捷键

### 开发者常用
- **Win + ` (反引号)** - 打开Windows Terminal（如果已安装）
- **Ctrl + Shift + P** - 打开命令面板（VS Code等编辑器）
- **F12** - 打开开发者工具（浏览器）
- **Ctrl + Shift + I** - 打开开发者工具（Chrome等浏览器）
- **虚拟桌面**：Win + Tab 创建新的虚拟桌面，提高工作效率














### 基础系统操作
- **Win + D** - 显示桌面
- **Win + E** - 打开文件资源管理器
- **Win + L** - 锁定计算机
- **Win + R** - 打开"运行"对话框
- **Ctrl + Shift + Esc** - 打开任务管理器
- **Alt + Tab** - 在打开的程序之间切换
- **Win + Tab** - 任务视图（虚拟桌面）
- **Alt + F4** - 关闭当前窗口或程序

### 文件管理
- **Ctrl + C** - 复制
- **Ctrl + X** - 剪切
- **Ctrl + V** - 粘贴
- **Ctrl + Z** - 撤销
- **Ctrl + Y** - 重做
- **Ctrl + A** - 全选
- **Ctrl + F** - 搜索
- **F2** - 重命名选中项目
- **Delete** - 删除选中项目
- **Shift + Delete** - 永久删除（不进入回收站）

### 浏览器通用快捷键
- **Ctrl + T** - 打开新标签页
- **Ctrl + W** - 关闭当前标签页
- **Ctrl + Shift + T** - 重新打开关闭的标签页
- **Ctrl + N** - 打开新窗口
- **F5** - 刷新页面
- **Ctrl + F5** - 强制刷新
- **Ctrl + +** - 放大页面
- **Ctrl + -** - 缩小页面
- **Ctrl + 0** - 恢复默认缩放
- **Home** - 跳转到页面顶部
- **End** - 跳转到页面底部

### 文本编辑
- **Ctrl + B** - 加粗
- **Ctrl + I** - 斜体
- **Ctrl + U** - 下划线
- **Ctrl + S** - 保存
- **Ctrl + O** - 打开文件
- **Ctrl + P** - 打印
- **Ctrl + H** - 替换
- **Ctrl + G** - 转到行

### 窗口管理
- **Win + ←** - 将窗口贴靠到屏幕左侧
- **Win + →** - 将窗口贴靠到屏幕右侧
- **Win + ↑** - 最大化窗口
- **Win + ↓** - 还原/最小化窗口
- **Win + Shift + ←** - 将窗口移动到左侧显示器
- **Win + Shift + →** - 将窗口移动到右侧显示器

### 截图工具
- **Win + Shift + S** - 打开截图工具
- **PrtScn** - 截取整个屏幕到剪贴板
- **Alt + PrtScn** - 截取当前活动窗口
- **Win + PrtScn** - 截取整个屏幕并保存到图片文件夹

### 系统工具
- **Win + I** - 打开Windows设置
- **Win + K** - 打开连接设备（投屏）
- **Win + X** - 打开高级用户菜单
- **Win + Pause/Break** - 打开系统属性
- **Win + U** - 打开轻松使用中心

### 特殊符号输入
- **Alt + 数字小键盘** - 输入特殊符号
  - Alt + 41420 = ✔
  - Alt + 41409 = ×
  - Alt + 41400 = ÷
  - Alt + 137 = ‰



### 高效操作组合
- **Ctrl + Shift + N** - 新建文件夹（在文件资源管理器中）
- **Shift + 右键** - 显示扩展上下文菜单
- **Ctrl + Shift + 右键** - 以其他用户身份运行程序
- **Win + 数字键 (1-9)** - 启动或切换任务栏上的程序

### 辅助功能
- **Win + +** - 打开放大镜
- **Win + -** - 缩小放大镜
- **Win + Esc** - 关闭放大镜
- **左 Shift + 左 Alt + Print Screen** - 切换高对比度模式

## 实用提示
1. **快速访问程序**：按Win键，然后直接输入程序名称
2. **虚拟桌面**：Win + Tab 创建新的虚拟桌面，提高工作效率
3. **多显示器**：使用Win + Shift + 方向键在显示器间移动窗口
4. **快速截图**：Win + Shift + S 可以选择截图区域，非常实用
