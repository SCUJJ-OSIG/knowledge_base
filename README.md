## 知识库 技术文档

这个是本人折腾的技术栈

### 🏛️ 体用双链架构

本知识库采用**体用分离**的双链架构，实现"一改全改"的知识管理：

```
体（Essence）→ 0-体/          概念的本质、原理、定义（单一事实源）
用（Application）→ 1-自用软件/  工具的个人配置、使用场景
     ↓
   3-场景/ → 问题场景的解决方案（体的组合应用）
```

**核心优势**：
- ✅ 一改全改：定义只在"体"层，双链自动同步
- ✅ 关系清晰：体用分离，场景独立
- ✅ 易于扩展：新工具只需在"体"层添加

### 📚 目录结构

#### 体层（单一事实源）
- **0-体/概念/** - 抽象概念定义（如 [[HTTP协议]]、[[Git版本控制]]）
- **0-体/工具/** - 工具的本质说明（如 [[Mise]]、[[Vim 编辑器]]）
- **0-体/技能/** - 跨场景的元技能

#### 用层（场景化应用）
- **1-自用软件/** - 个人配置 + 工具组合用法（引用体层概念）
- **2-技术文章/** - 专题性技术文档
- **3-场景/** - 按问题场景组织（如 [[部署服务器场景]]、[[团队协作场景]]）
- **4-全栈/** - 综合性知识图谱

#### 其他
- **0-blog/** - 博客文章
- **3-skills/** - 技能相关
