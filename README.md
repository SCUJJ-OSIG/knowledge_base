## 使用方法

clone 本仓库，使用黑曜石打开，安装一个黑曜石插件 git，就可以愉快使用了。

1.添加文档原则是 新建文件夹，在新建文件，把图片保存到原当前文件所在文件夹下指定的assets 文件中。 按下图设置，你粘贴的图片自动到这个位置

![[Pasted image 20251012142146.png]]
始终更新内部链接可以点上，这样你修改文件名，依赖该文件的链接也会同时修改！！


2. 要贡献的话，直接pr 就好

## 📚 目录结构

### 01-编程基础
- **计算机基础**: 基础概念、系统命令、网络知识
- **数据结构与算法**: 核心算法、数据结构
- **设计模式**: 常用设计模式、架构模式
- **网络协议基础**: HTTP、WebSocket、TCP/IP等

### 02-TypeScript全栈开发
- **TS基础与类型系统**: TypeScript语法、类型系统
- **前端框架**: Vue、React、鸿蒙开发、小程序
- **后端运行时**: Node.js、Bun、Deno
- **全栈框架**: Next.js、Nuxt.js、SvelteKit
- **数据库与ORM**: SQL、NoSQL、ORM工具
- **工程化与部署**: 构建工具、包管理、测试、部署

### 03-Java企业级开发
- **Java基础与进阶**: Java语言、JVM、并发
- **Spring框架生态**: Spring Boot、Spring Cloud
- **微服务架构**: 分布式系统、服务治理
- **消息队列**: RabbitMQ、Kafka等
- **缓存技术**: Redis、Ehcache
- **企业级部署**: Docker、Kubernetes、Jenkins

### 04-移动与跨平台开发
- **Android原生开发**: Android SDK、Kotlin/Java
- **iOS开发**: Swift、Xcode
- **跨平台方案**: React Native、Flutter、UniApp
- **小程序开发**: 微信小程序、支付宝小程序

### 05-DevOps与基础设施
- **Linux系统管理**: Ubuntu、CentOS、命令行
- **网络安全**: 防火墙、SSL/TLS、安全配置
- **容器化技术**: Docker、Kubernetes
- **CI-CD流水线**: GitHub Actions、Jenkins
- **云服务与监控**: AWS、阿里云、监控工具

### 06-测试与质量保证

- **代码质量管理**: 代码规范、静态分析

### 07-开发工具与效率
- **Git版本控制**: Git命令、协同开发
- **IDE与编辑器**: VS Code、IntelliJ IDEA
- **效率软件**: uTools、 Alfred、效率工具
