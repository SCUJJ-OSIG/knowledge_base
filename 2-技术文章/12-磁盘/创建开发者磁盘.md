> 为什么创建开发者磁盘，文件打开快，缓存有优化

win +i 打开设置 输入 管理磁盘和卷
如下
![[PixPin_2026-04-24_15-30-28.png]]


> VHD:虚拟硬盘文件格式
> VHDX:提供了更强的性能和数据保护能力

| 特性   | VHD (旧版)  | VHDX (新版)                        |
| :--- | :-------- | :------------------------------- |
| 最大容量 | 2 TB      | 64 TB                            |
| 数据保护 | 不支持，断电易损坏 | 支持，通过日志记录防止数据损坏                  |
| 性能优化 | 基本        | 更优，支持4KB逻辑扇区                     |
| 兼容性  | 广泛，支持旧版系统 | 需要 Windows 8 / Server 2012 或更高版本 |

点击创建开发者人员驱动器

创建新的vhd,
![[PixPin_2026-04-24_15-32-23.png]]

位置不要选择c盘，选择你磁盘空间较大的位置
![[PixPin_2026-04-24_15-32-45.png]]

点击创建

然后可以把我的文档 我的桌面迁移到新的dev 盘。
