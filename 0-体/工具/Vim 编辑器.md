# Vim 编辑器

> 一句话定义： modal(模态) 文本编辑器，通过模式切换实现高效的文本编辑

## 本质定位

**Vim = 模态编辑 + 组合语法 + 高度可定制**

- 前身：Vi (1976)
- 版本：Vim (Vi IMproved, 1991)
- 哲学：专注于文本编辑的效率工具

## 核心原理

### 模态设计

Vim 的核心创新是**模态编辑**，不同模式下按键有不同的含义：

```
普通模式 (Normal)     ←→     插入模式 (Insert)
    ↓  ↑                            ↓
可视模式 (Visual)    ←→     命令行模式 (Command)
```

- **普通模式**：导航、删除、复制、粘贴等命令
- **插入模式**：输入文本
- **可视模式**：选择文本
- **命令行模式**：执行命令、搜索、保存等

### 组合语法

Vim 的命令遵循**动词 + 名词**的组合语法：

| 动词 (操作) | 名词 (对象) | 结果 |
|------------|------------|------|
| d (delete) | w (word) | dw 删除一个词 |
| c (change) | $ (行尾) | c$ 删除到行尾并进入插入模式 |
| y (yank) | y (当前行) | yy 复制当前行 |
| > (缩进) | } (段落) | >} 缩进整个段落 |

### 文本对象

Vim 将文本结构化为可操作的对象：

- `w` - 词 (word)
- `s` - 句子 (sentence)
- `p` - 段落 (paragraph)
- `(`, `{`, `[` - 括号内内容
- `'`, `"` - 引用内内容

## 主要功能

### 1. 高效导航

- `h/j/k/l` - 左下上右移动
- `w/b` - 按词前进/后退
- `0/$` - 行首/行尾
- `gg/G` - 文件首/文件尾
- `:/搜索词` - 搜索跳转

### 2. 文本操作

- `dd` - 删除当前行
- `yy` - 复制当前行
- `p/P` - 粘贴到光标后/前
- `u/Ctrl+r` - 撤销/重做
- `.` - 重复上次操作

### 3. 可视化选择

- `v` - 字符选择
- `V` - 行选择
- `Ctrl+v` - 块选择 (列编辑)

### 4. 多窗口与标签页

- `:split/:vsplit` - 水平/垂直分屏
- `Ctrl+w` + 方向键 - 切换窗口
- `:tabnew` - 新建标签页

### 5. 宏与自动化

- `q{寄存器}` - 开始录制
- `q` - 停止录制
- `@{寄存器}` - 执行宏
